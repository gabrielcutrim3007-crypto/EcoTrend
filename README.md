# EcoTrend

Nome: Gabriel Cutrim, RM: 568059

## Descrição do Projeto

EcoTrend Store é um e-commerce de produtos sustentáveis e ecológicos, voltado para promover um estilo de vida consciente e sustentável. O site oferece uma experiência de compra interativa, destacando produtos que respeitam o meio ambiente, desde roupas e acessórios até itens de tecnologia verde e produtos para cuidados pessoais.

## Tipos de Produtos

Roupas e acessórios sustentáveis: camisetas e vestuário feitos com materiais ecológicos.

Produtos de beleza e cuidados pessoais naturais: sabonetes, shampoos e cosméticos naturais.

Itens para casa sustentáveis: utensílios de cozinha e kits de talheres ecológicos.

Tecnologia verde: carregadores solares e outros dispositivos sustentáveis.

## Funcionalidades
Manipulação do DOM

Carrinho de Compras Dinâmico: os usuários podem adicionar produtos ao carrinho e visualizar a lista em tempo real na sidebar.

Filtragem de Produtos: os usuários podem filtrar produtos por categoria sem recarregar a página.

Storage e JSON

Persistência do Carrinho: o carrinho é armazenado no localStorage, permitindo que os itens permaneçam entre sessões.

Produtos Dinâmicos: a lista de produtos é carregada a partir de um arquivo JSON (produtos.json) e exibida dinamicamente na página.

Interatividade

Feedback ao usuário via alertas ao adicionar produtos ao carrinho.

Remoção individual de produtos e esvaziamento total do carrinho.

Contador de itens atualizado automaticamente no ícone do carrinho.

## Tecnologias Utilizadas

HTML5 & CSS3: estrutura e estilização das páginas.

JavaScript: manipulação do DOM, eventos, filtros e carrinho persistente.

JSON: armazenamento e carregamento da lista de produtos.

LocalStorage: persistência dos dados do carrinho.

Bootstrap 5: framework para layout responsivo e componentes visuais.

Font Awesome: ícones do carrinho e redes sociais.

Google Fonts (Poppins): tipografia moderna e clean.

## Observações

O carrinho de compras é persistente utilizando localStorage.

Todos os produtos são carregados diretamente de produtos.json.

O site é responsivo e otimizado para dispositivos móveis e desktop.
